# Purpose

Represents one execution of a regression test.

---

# Run Metadata

A Run contains:

- Title
- Description
- Start Time
- End Time
- Environment
- Status

Examples:

- Sprint 35 Baseline
- Sprint 36 Regression
- Release Candidate Validation

---

# Status

- Pending
- Running
- Completed
- Failed
- Cancelled

---

# Execution

- A Run executes multiple Requests.
- Each Request generates one Response Result.
