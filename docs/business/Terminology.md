# Terminology

- **Project** — business system under test.
- **API Definition** — API endpoint definition.
- **Request** — reusable API test request.
- **Run** — execution of multiple requests.
- **Run Result** — response generated by a request execution.
- **Compare** — comparison between two runs.
- **Compare Detail** — field-level differences.
- **Ignore Rule** — fields excluded from comparison.
- **AI Summary** — natural language explanation of compare results.
