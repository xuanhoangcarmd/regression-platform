Each row is a request. The file must include a Title column as the request title; the remaining columns are fields in the body. The system automatically converts them into a query string (if the API is GET) or a JSON request body (other methods). Rows missing a Title will be skipped. An optional Description column is stored as the request's description (not sent in the body).

Nested bodies: use a dotted column name to nest — VehicleBuffersRequest.Vin becomes {{ '{' }}"VehicleBuffersRequest":{{ '{' }}"Vin":…{{ '}}' }}; a cell containing JSON text (starting with {{ '{' }} or [) is embedded as a real object/array — e.g. put ["…","…"] in an OemModuleRaw column for an array of strings.
